TrustVault

Windows Desktop Application

One console for customers, accounts, cash movement, credit, and controls.

TrustVault is a JavaFX and MySQL banking operations application designed for branch-style workflows: onboarding, account creation, deposits, withdrawals, transfers, statements, audit trails, loans, and fixed deposits.

Deployment Windows

Packaged with `jpackage` and delivered as a desktop app, not a browser app.

Java 21 JavaFX MySQL GitHub Actions

What It Handles

Operational coverage without tool-switching.

  • Admin login with password hashing and audit logging.
  • Customer onboarding and account lifecycle management.
  • Deposits, withdrawals, and transfer processing.
  • Statement export for account-level transaction history.
  • Loan issuance, repayment tracking, and fixed deposit records.
